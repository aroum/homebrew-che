# Homebrew Tap for `che`

Official Homebrew Tap repository for **`che`** — dual-pane terminal file manager written in Rust.

---

## 🛠 Installation

Add the tap and install `che` on macOS or Linux:

```bash
brew tap aroum/che
brew install che
```

---

## 🚀 Usage

Launch the dual-pane file manager:

```bash
che
```

Launch the CLI multirename tool:

```bash
ch
```
